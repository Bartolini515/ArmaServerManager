# ArmaServerManager

ArmaServerManager is a web-based server management tool designed for the FOG community. It was created to make Arma 3 server administration easier, safer, and more accessible for users who need to work with Arma missions without requiring direct access to the server itself.

The project simplifies the process of turning the server on and off, gives users the ability to create individual mission instances for testing, and provides a secure way to upload mission files. This makes it much easier to prepare, test, and manage missions in a controlled environment.

ArmaServerManager was built to improve the overall workflow of server operations and mission development. Instead of relying on manual server access or less organized methods, it offers a structured interface that helps users manage important tasks efficiently while maintaining security and control.

## Features

- Simple server start and stop control
- Individual mission instance creation for testing
- Secure mission file upload system
- Server access control without sharing direct credentials
- Designed specifically for the FOG community workflow
- Improved mission testing and deployment process
- Convenient and user-friendly management interface

## Purpose

The main goal of ArmaServerManager is to make server handling and mission management easier for the FOG community. It reduces the need for direct server access, improves security, and gives users a practical way to test and upload missions in a clean, organized way.
